# Euphemia Haynes — Mathematics as an Open Door

An animated film about the mathematician and teacher Euphemia Lofton Haynes
(1890–1980), the first African American woman to earn a Ph.D. in mathematics
(Catholic University of America, 1943). It is made with
[Manim Community Edition](https://www.manim.community/), with narration
generated by [Kokoro](https://github.com/hexgrad/kokoro) text-to-speech.

The film has two lessons:

- **Lesson I — Beyond Computation.** Haynes's ideas about teaching, drawn from
  her 1945 address "Mathematics — Symbolic Logic": structure over
  calculation, understanding over imposition, inquiry, constant and
  variable, relationship, and degrees of freedom. It ends as the plane lifts
  into space and MORE POSSIBILITIES rises out of it.
- **Lesson II — Discovery.** What her own mathematics looked like. A tangent
  line rolls around the three-cusped quartic from her thesis while its dual
  curve draws itself, and the curve's Plücker counts stay fixed as it
  deforms. The Simson lines of Lesson I's 3-4-5 triangle then sweep out the
  same curve. Polygons close in on a circle, the circle becomes a door
  marked MATH, and it opens onto LIFE, OPPORTUNITY and FREEDOM.

The end credits list sources, and the time at which each quotation is heard.

## Quick start

From inside the repository, with an environment that has Manim and Kokoro
(see [Setup](#setup)):

```bash
python generate_movement1_audio.py --voice af_heart --speed 0.94
python generate_movement2_audio.py --voice af_heart --speed 0.94
manim -pql haynes_film.py HaynesFilm    # low-resolution preview
manim -pqh haynes_film.py HaynesFilm    # 1080p
```

The narration is mixed into the MP4; no separate audio step is needed. The
video is written under `media/videos/haynes_film/`.

## Files

In the code and file names the lessons are still called movements
(`haynes_movement1.py` is Lesson I, `haynes_movement2.py` is Lesson II); only
the on-screen word changed.

| File | What it is |
|---|---|
| `haynes_film.py` | The whole film: title card, Lesson I, Lesson II, one set of end credits. |
| `haynes_movement1.py` | Lesson I, plus the shared pieces: the title card, the credits, the narration timing (`NarratedScene`), `CurveText` / `write_along`, `SwingingDoor`, and the door finale. |
| `haynes_movement2.py` | Lesson II: the duality scene, the Simson lines, and the ending with the door. |
| `haynes_movement1_text.json` | Every word of Lesson I (narration and on-screen text), the title card and the credits. |
| `haynes_movement2_text.json` | Every word of Lesson II. |
| `generate_movement1_audio.py`, `generate_movement2_audio.py` | Generate each lesson's narration with Kokoro and write `audio/movement1/` or `audio/movement2/`, with a manifest of clip lengths and sentence start times. |
| `haynes_curves.py` | The curves of Haynes's thesis, their duals and Plücker numbers, ported from the Sage code by Edray Goins and David Joyner (`haynes-project-code_goins2.sage`) to plain Python/numpy, so Sage is not needed to render. |
| `check_haynes_curves.py` | Checks that port against the Sage algorithm (redone in sympy) and the results recorded in the Sage file. |
| `MOVEMENT2_PLAN.md` | The plan Lesson II was built from. |
| `assets/haynes_portrait_lineart.png` | Public-domain line drawing of Haynes, used by the title card and the credits. |
| `haynes_scene1.json`, `generate_scene1_audio.py` | An earlier stick-figure scene made with PAM; not part of the film, and it needs PAM installed. |

The `audio/` and `media/` folders are generated on your machine and are not
stored on GitHub.

## Setup

### 1. Get the code (first time only)

```bash
cd ~/Projects
git clone https://github.com/wdjoyner/haynes.git
cd haynes
```

To pick up later changes, run `git pull` inside `~/Projects/haynes`.

### 2. An environment with Manim and Kokoro

Any Python environment with these works. For example, with conda:

```bash
conda create -n haynes-manim python=3.11
conda activate haynes-manim
pip install manim kokoro soundfile sympy
```

Manim also needs LaTeX (for the equations) and ffmpeg; see
[Manim's installation guide](https://docs.manim.community/en/stable/installation.html).
After the first time, just run `conda activate haynes-manim`.

### 3. Narration

```bash
python generate_movement1_audio.py --voice af_heart --speed 0.94
python generate_movement2_audio.py --voice af_heart --speed 0.94
```

Run these again whenever you change any `narration` text. Kokoro speaks each
sentence separately, with a short pause between them (given a long passage
in one piece, it tends to rush or drop words). The manifests record each
clip's length and every sentence's start time, and the animation reads them,
so it stays in sync on its own.

To preview Lesson II before recording, `python generate_movement2_audio.py
--placeholder` writes silent clips of estimated length in a few seconds.

### 4. Render

```bash
manim -pql haynes_film.py HaynesFilm                 # whole film, preview
manim -pqh haynes_film.py HaynesFilm                 # whole film, 1080p

manim -pql haynes_movement1.py HaynesMovementOne     # Lesson I alone, with credits
manim -pql haynes_movement2.py HaynesMovementTwo     # Lesson II alone
manim -pql haynes_movement2.py DualityScene          # just the duality scene
manim -pql haynes_movement2.py SimsonClosing         # just the Simson lines
```

If a narration manifest is missing, the render stops and names the script to run.

### 5. Chapters for YouTube

Each render of `HaynesFilm` prints chapter times and writes them to
`youtube_chapters.txt`, ready to paste into the video description. They come
from that render's narration, so render with the final narration first. The
chapter names are in `haynes_movement2_text.json` under `film.chapters`.

## Editing the words

All text lives in the two JSON files; the Python files never need to change
for a wording edit.

- **Narration** may be one string or a list of sentences.
- **Cues.** Many beats wait for a particular phrase to be spoken (UNDERSTANDS
  appears with "He understands it", the door opens on "knowledge can open
  paths", and so on). Each scene's `cues` list names those phrases; if you
  reword a sentence, keep its cue matching it word for word.
- **Credits** are in `haynes_movement1_text.json`. Line kinds: `b` bold, `h`
  small italic heading, `t` text, `s` small text, `""` a blank gap. The
  `quotations` entry is replaced by the list of quotations from both lessons,
  with the time at which each is heard.

## Checking the mathematics

```bash
python check_haynes_curves.py
```

This recomputes every curve of the Sage file (resultants, duals, degree,
class, nodes, cusps, bitangents, flexes) and compares them with the numpy
port and with the results recorded in the Sage file. It also checks the
facts the animation relies on, for example that a projective change of
coordinates carries Haynes's three-cusped quartic exactly onto the deltoid.

## Notes on the animation

- The film is plain 2-D (`Scene`, not `ThreeDScene`) so layering is reliable.
  Depth is faked where it is needed: the door's swing (`SwingingDoor`), the
  floor in perspective (`FloorPerspective`), and the solid lettering of MORE
  POSSIBILITIES (`ExtrudedWord`, layers stacked toward a vanishing point).
- `CurveText` lays a word along any curve, reading left to right;
  `write_along` reveals its letters as the curve is drawn, and calling
  `place_on` from an updater lets a word ride a moving curve.
- The dual curve is drawn by polar reciprocity: each tangent line of the
  quartic is shown as its pole in a fixed circle.
