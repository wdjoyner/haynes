# Euphemia Haynes — Mathematics as an Open Door

An animated film about the mathematician and teacher Euphemia Lofton Haynes
(1890–1980), made with Manim. It has two lessons: Lesson I is complete; Lesson II is in progress.

In the code and file names the lessons are still called movements
(`haynes_movement1.py` is Lesson I, `haynes_movement2.py` is Lesson II); only
the on-screen word changed.

Movement I does not depend on PAM for its visuals. The `haynes_scene1.json` /
`generate_scene1_audio.py` pair is an earlier PAM stick-figure scene and does
need PAM installed.

## Files

- `haynes_movement1_text.json` — **every word in the film**: the narration, all on-screen words, the title card and the credits. Edit text here; the two scripts below both read it.
- `haynes_movement1.py` — Manim animation. It mixes narration into the MP4 with Manim `add_sound()`.
- `generate_movement1_audio.py` — generates the narration WAV files with Kokoro and writes a duration manifest.
- `assets/haynes_portrait_lineart.png` — public-domain line drawing of Haynes, converted to cream line art on a transparent background; used by the title card and the end credits.
- `audio/movement1/` — generated locally; WAV files are not committed by this setup.

## 1. Get the code (first time only)

```bash
cd ~/Projects
git clone https://github.com/wdjoyner/haynes.git
cd haynes
```

## 2. Activate the environment

The film needs Manim and Kokoro, which are already installed in PAM's
environment, so reuse it:

```bash
source ~/Projects/pam/.venv/bin/activate
```

To pick up later changes, run `git pull` inside `~/Projects/haynes`.

## 3. Generate narration (from inside `haynes/`)

```bash
python generate_movement1_audio.py \
    --voice af_heart \
    --speed 0.94
```

Expected output:

```text
audio/movement1/m1_00_opening.wav
audio/movement1/m1_01_reason.wav
audio/movement1/m1_02_inquiry.wav
audio/movement1/m1_03_constant_variable.wav
audio/movement1/m1_04_relationships.wav
audio/movement1/m1_05_freedom.wav
audio/movement1/audio_manifest.json
```

## 4. Low-resolution preview

```bash
manim -pql haynes_movement1.py HaynesMovementOne
```

Manim should write an MP4 under `media/videos/haynes_movement1/.../HaynesMovementOne.mp4`.
The narration is embedded in that MP4; no separate ffmpeg merge step is required.

## 5. 1080p render

```bash
manim -pqh haynes_movement1.py HaynesMovementOne
```

## The whole film

`haynes_film.py` plays the title card, Lesson I, Lesson II and one set of end
credits, as a single render. The quotation time stamps in the credits count
from the start of the film, and "We will teach … we will inspire" closes it
once. Generate both lessons' narration first, then:

```bash
manim -pql haynes_film.py HaynesFilm    # preview
manim -pqh haynes_film.py HaynesFilm    # 1080p
```

Each lesson can still be rendered alone (with its own credits) for quick checks.

## Lesson II (in progress)

Built so far: scene 11 (duality) and the Simson-line part of the closing.
See `MOVEMENT2_PLAN.md` for the whole movement.

- `haynes_movement2_text.json` — every word in Movement II, as for Movement I.
- `haynes_movement2.py` — the Manim scenes. It imports `CurveText`, `write_along`, the narration timing and CHALK from `haynes_movement1.py`.
- `haynes_curves.py` — the thesis curves from `haynes-project-code_goins2.sage` (Goins and Joyner), ported to plain Python/numpy so Sage is not needed to render.
- `check_haynes_curves.py` — checks that port against the Sage algorithm (redone in sympy) and the outputs recorded in the Sage docstrings. Run `python check_haynes_curves.py`; it needs `pip install sympy`.
- `generate_movement2_audio.py` — narration for Movement II. With `--placeholder` it writes silent clips of estimated length instead, for previewing before recording.

```bash
python generate_movement2_audio.py --voice af_heart --speed 0.94
manim -pql haynes_movement2.py HaynesMovementTwo     # whole movement so far
manim -pql haynes_movement2.py DualityScene          # scene 11 only
manim -pql haynes_movement2.py SimsonClosing         # closing only
```

Each Movement II beat waits for the sentence that describes it (found by the
`cues` in the text file), so re-recording the narration keeps it in sync.

## Notes

- The animation requires the generated `audio_manifest.json`; if it is absent, the scene stops with an explicit instruction to run the audio generator.
- The scene uses only Manim core geometry/animation primitives so it is isolated from PAM version skew.
- Curved typography is generated by positioning and rotating individual glyphs along a Manim curve.
- The scene is plain 2-D (`Scene`, not `ThreeDScene`) so z-index layering is reliable: the opaque door always hides what is behind it.
- Both doors use `SwingingDoor`, a hinged panel with fake perspective. The final door reads MATH while closed and swings open to reveal LIFE.
- `CurveText` lays a word along any curve (or any function `t -> point`), reading left to right; `write_along` reveals its letters in step with the curve being drawn; calling `place_on` from an updater lets a word ride a moving curve (VARIABLE on the changing circle).
- Film order: title card → opening → five scenes → LIFE / OPPORTUNITY / FREEDOM finale → end credits.
- To change wording, edit `haynes_movement1_text.json` only. If you change any `narration`, rerun `generate_movement1_audio.py`; the animation picks up the new clip lengths automatically.
